# Airflow Tutorial Files

The respository contains the SQL Scripts and libraries you will need to complete the Airflow tutorial. The **sql_scripts** directory contains the SQL needed to create the [stage] schema while the **dags** directory contains the Airflow operator code and the code to populate all of the dimensions of the Sakila data warehouse, other than dim_time, dim_date, and dim_film, as well as the fact table.

Within the **dags** folder the **sql** folder contains all of the SQL scripts used to do the transforms as well as some scripts for handling foreign keys.

Use these files, in conjunction with the Airflow Tutorial documentation, to complete your build of the Sakila Data Warehouse.
